Instrucciones rápidas:

1. Descomprime el archivo ZIP.
2. Abre Microsoft Edge y escribe: edge://extensions/
3. Activa 'Modo desarrollador' y haz clic en 'Cargar descomprimida' o 'Cargar sin empaquetar'.
4. Selecciona la carpeta 'notes_edge_extension'. Aparecerá el icono y podrás abrir el popup para gestionar notas.

Funcionalidades:
- Crear notas con título y contenido.
- Editar notas existentes (clic en 'Abrir' en la lista).
- Eliminar notas.
- Las notas se guardan en chrome.storage.local (persisten en el navegador).

Nota: para empaquetar oficialmente la extensión y distribuirla, revisa las políticas de Microsoft Edge Add-ons.
